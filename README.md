# dotfiles

zsh, neovim and shell completions. Themes are generated by
[embe221ed/interdotensional](https://github.com/embe221ed/interdotensional).

## If your shell is broken

```sh
zsh -f                                  # a shell that reads no config at all
sh /opt/dotfiles/rescue.sh              # repoint every link at this checkout
sh /opt/dotfiles/rescue.sh --to <root>  # ...or at some other tree
```

`rescue.sh` needs nothing on `$PATH` and lives inside the repo, so it is present
wherever the clone is. It will not touch `~/.zshrc` or `~/.zshenv` on macOS
unless you pass `--with-zsh` — see *zsh scope* below.

## Install

```sh
git clone https://github.com/embe221ed/dotfiles /opt/dotfiles
cd /opt/dotfiles
./install.sh --dry-run     # see this machine's real manifest
./install.sh               # link it
```

`install.sh` derives its own root, so the repo works checked out anywhere. Flags:
`--lang sui|aptos` (treesitter/LSP profile, default `sui`), `--dry-run`,
`--check`, `--force` (move an existing real file aside), `--with-zsh`.

**Run `./install.sh --dry-run` to see what a given machine gets — do not
reconstruct it from prose.** The manifest is OS-conditional and differs in both
directions: macOS omits `~/.zshrc` and `~/.zshenv`, and adds `silicon/config`
plus the two `oh-my-zsh/*.zsh-theme` prompt themes into `$ZSH_CUSTOM/themes/`.

## Prerequisites this repo does not install

- **oh-my-zsh**
- three `$ZSH_CUSTOM/plugins` clones: `fzf-tab`, `zsh-autosuggestions`,
  `fast-syntax-highlighting`

`zsh/zshrc` guards its `source $ZSH/oh-my-zsh.sh`, so a machine without them
gets a plain-but-working shell rather than a hard error mid-file.

## zsh scope

`zsh/` is for the **Linux VPS and the dev container**. The macOS machine keeps
its own `~/.zshrc`, `~/.zshenv` and `~/.zprofile` — they are independent files
that diverged, not copies. `install.sh` and `rescue.sh` both leave them alone on
Darwin unless you pass `--with-zsh`. Unifying them is a tracked follow-up; see
`MACHINES.md`.

## This repo does not depend on `scripts`

`oh-my-zsh/*.zsh-theme` prefer `determine_system.sh` when it is resolvable **by
name** (`$DETERMINE_SYSTEM`, then `$PATH`) and otherwise fall back to plain
`uname`, which returns the identical string. There is no path to `scripts`
anywhere in this tree.

## Where things live

| Repo | Owns |
|---|---|
| **dotfiles** (this) | `zsh/`, `nvim/`, `zsh/completions/`, `git/` (shared git aliases), `kitty/` themes, `blink/`, `ipython/`, `colorls/`, `silicon/`, `.ripgreprc` |
| [**scripts**](https://github.com/embe221ed/scripts) | utilities, CTF tooling, the dev container image, and `utils/determine_system.sh` |
| [**interdotensional**](https://github.com/embe221ed/interdotensional) | the theme generator: `nvim/lua/*.generated.lua`, `$ZSH_CUSTOM`, `~/.tmux.conf`, `~/.config/colorls`, `~/.config/kitty/kitty.conf`, and **all** of `~/.config/ghostty` and `~/.config/zellij` |

`embe221ed/tmux-powerline` is a fourth repo this one no longer touches — its
three theme files were removed. It is orphaned and can be archived.

## Notes

- `git/aliases.gitconfig` holds the shared git aliases (`git aliases` lists
  them; `git <alias> -h` shows usage). `install.sh` links it to
  `~/.config/git/aliases.gitconfig` and adds
  `include.path = <that path>` to the global git config, exactly once. The rest
  of `~/.gitconfig` — identity, credential helpers, per-machine tweaks — stays
  out of the repo on purpose, and the repo file is **not** the auto-read
  `~/.config/git/config` slot, so `git config --global` writes can never land
  in the repo through the symlink.
- `nvim/lua/globals.lua` and `nvim/lua/ui/colors.lua` are **committed shims**.
  They `pcall`-load gitignored `*.generated.lua` siblings that `interdot link`
  fills, and work without them: a clone with no generator starts **unthemed**,
  not broken. `:lua =vim.g.interdot_generated` says which happened.
- `lazy-lock.json` is committed on purpose — reproducing the editor on a new
  machine is the point. `nvim/spell/en.utf-8.add` is committed too; only the
  compiled `.spl` is ignored.
- `silicon/config` is a dotfile, not vendored tooling: silicon reads it from
  `~/.config/silicon/config`, and `scripts`' `utils/export_to_pdf.sh` passes
  none of the four settings it sets (`--font`, `--pad-vert`, `--pad-horiz`,
  `--tab-width`).
- **The pruned files live in `embe221ed/scripts`' history, not here** — the three
  tmux-powerline themes, the eleven ghostty shaders, the two oh-my-zsh themes in
  their old form, and the kitty/ghostty/zellij generated symlinks. Recovering one
  in two years means remembering it was in the other repo's log.
- `origin/blink` was fully merged into `main` and is not carried over.
